## 2. 服务说明 / The Service

Percent 是一个 macOS 桌面工具，提供以下功能：

Percent is a macOS desktop tool that provides:

- **按 Enter 留痕** — 微信里按回车，这条对话自动存到本地
- **Draft a reply** — 截屏 + LLM 生成回复建议，⌘V 粘贴（**不替你发**）
