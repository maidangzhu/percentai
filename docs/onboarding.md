# Percent Onboarding 流程（产品 spec）

> 用户**首次启动 → 完整使用**的端到端路径。所有改动都遵循"不阻塞、可跳过、bannner 提醒"原则。

最后更新：2026-06-18（v0.1.8）

---

## 1. 设计原则

1. **零阻塞**：启动后**立刻进主界面**。任何配置项都从主界面里点进去。
2. **永久可见入口**：所有"应该配置但用户跳过了"的项目，在主界面有固定入口（侧边栏 / banner / 头像）。
3. **区分必填和可选**：
   - **必填**：BYOK provider key（AI 功能要）
   - **强推荐**：macOS 权限（截屏 + 辅助功能），没有也能开 app，但 AI 工作流降级
   - **可选**：Percent 账号（云同步；不登录纯本地）
4. **每个 banner 独立消失**：用户解决一个问题，对应 banner 消失；其他 banner 不联动。
5. **不重复弹**：用户 dismiss 某个 banner 后，本次 session 内不再显示（除非问题再次出现）。

---

## 2. 启动 → 主界面 流程

```
[Tauri 启动]
   ↓
[localStorage 读 percent.welcomed]
   ↓ true (老用户)        ↓ false (新用户)
[直接进主界面]    [WelcomeView 一次性]
                       ↓ 点击继续
                       [localStorage.percent.welcomed = "true"]
                       ↓
                       [进主界面]
```

**WelcomeView**（一次性，新用户）：
- 标题："欢迎用 Percent"
- 一段话：本机 AI 伙伴、数据全在本地、用 BYOK 直连 provider
- 一个 CTA："开始使用" → 标记 welcomed + reload

不再有"配权限"、"配 BYOK"步骤。**这些配置都在主界面里做**。

## 3. 主界面布局

```
┌─────────────────────────────────────────────────────┐
│  [BANNER 区] (顶部，按优先级堆叠，0-N 条)             │
├──────────┬──────────────────────────────────────────┤
│          │                                          │
│  侧边栏   │                                          │
│          │            [当前页面内容]                 │
│  首页    │                                          │
│  日志    │                                          │
│  联系人  │                                          │
│  任务    │                                          │
│  权限    │                                          │
│  设置    │                                          │
│          │                                          │
│  ─────   │                                          │
│ [账号]   │                                          │
│          │                                          │
└──────────┴──────────────────────────────────────────┘
```

### 3.1 Banner 区（顶部，最多同时 3 条，按严重度排）

**优先级**（高到低）：

1. **🔴 BYOK 未配置**（红色，醒目）
   - 文案："AI 功能未配置。客户端不会自动调用 LLM —— 去设置 → BYOK 填一个 provider 和 key。"
   - 按钮："去配置" → 跳 Settings → 滚动到 BYOK section

2. **🟡 macOS 权限未授权**（黄色，普通）
   - 文案："推荐授权屏幕录制 + 辅助功能，以启用截屏 / 帮我回 / 记任务。"
   - 按钮："去授权" → 跳侧边栏"权限"页

3. **🔵 Percent 账号未登录**（蓝色，普通）
   - 文案："登录 Percent 账号后可云同步聊天记录 / 截图（数据走 Percent 服务器）。不登录也能用，只是数据只在本机。"
   - 按钮："登录" → 打开 AuthView 弹窗（**模态弹窗，不挡主界面**）

**Banner 行为**：
- 问题解决后立即消失（重新检测）
- 多个 banner 同时显示时，高度累加但**不挤掉彼此**
- 每个 banner 有右侧关闭按钮 → dismiss（本次 session 不再显示，除非问题再次出现）

### 3.2 侧边栏

**导航项**（顺序）：
1. 首页
2. 截屏日志
3. 联系人
4. 任务
5. **权限**（永久可见）
6. 设置
7. local 测试（开发菜单，仅 dev 模式）

**底部账号区**：
- 未登录：圆形图标（默认头像 placeholder）+ 文字"未登录"，点击 → 打开登录模态
- 已登录：邮箱头像 + "同步状态" toggle + 退出菜单
- 永远在底部，**不挡视野**

### 3.3 主区域

按侧边栏选中显示：首页 / 日志 / 联系人 / 任务 / 权限 / 设置。

## 4. 各配置项的产品定位 + 文案

### 4.1 BYOK provider key

**定位**：**必填**（AI 功能的输入）。

**入口**：
- 顶部 banner（最显眼）
- Settings → 第一个 section
- 不在 WelcomeView 引导（避免阻塞）

**文案**（统一口径）：
> **BYOK（自带 API key）**：客户端直连你配置的 LLM provider（OpenAI / Anthropic / Moonshot / MiniMax 等）。**完全不经 Percent 服务器**，数据永远在你 Mac 上。  
> 你只需要：(1) 选 provider (2) 填模型 (3) 填 baseUrl（如有）(4) 填 API key → 保存。

**保存后**：BYOK banner 立刻消失。

### 4.2 macOS 权限

**定位**：**强推荐**（AI 工作流要截屏 + 识别前台 app）。

**权限项**：
- 屏幕录制（截屏要）
- 辅助功能（识别前台 app）
- 输入监控（监听全局 Enter 按键）

**入口**：
- 顶部 banner（黄色）
- 侧边栏"权限"页（永久）
- **不在 WelcomeView 引导**

**权限页布局**：
- 列出 3 项权限 + 状态（已授权 / 未授权）
- 未授权项右边按钮："去授权" → 打开 macOS 系统设置对应页
- 已授权项：显示 "✓ 已授权"
- 顶部一个 "重新检查" 按钮（手动刷新状态）
- 不阻塞用户操作，没授权的项也会显示（标黄）

**没授权会怎样**：
- 截屏相关功能（按 Enter / 「帮我回」/ 「问屏幕」）显示提示"需要屏幕录制权限"
- 其他功能（日志、联系人、任务）正常用

### 4.3 Percent 账号

**定位**：**可选**（用于云同步、未来功能）。

**入口**：
- 侧边栏底部账号区（点击打开登录模态）
- 顶部 banner（蓝色，可 dismiss）
- 未来：登录后展示云同步状态

**模态弹窗布局**：
- 标题："登录 Percent（可选）"
- Tab：登录 / 注册
- 邮箱 + 密码
- 一个按钮："登录" 或 "注册"
- "跳过" 按钮（关闭弹窗，不登录）
- 不登录能用，只是数据只在本机

**登录后**：
- 侧边栏底部展示头像 + 邮箱
- 一个 "云同步" toggle（开关）
- "退出登录" 菜单项
- 顶部蓝色 banner 消失

**云同步内容（未来 PR）**：
- 聊天记录 / 联系人 / 任务
- 截图审计（不上传截图本身，只上传元数据）
- 不上传 BYOK key / 不上传 prompt 内容

> **MVP（v0.1.x）登录只展示 UI，不实际同步**。同步功能在 v0.2+ 实现。

## 5. 各 banner 的 dismiss 行为

| Banner | Dismiss 后行为 |
|---|---|
| BYOK 未配置 | 本 session 不再显示；下次启动重新评估 |
| 权限未授权 | 本 session 不再显示；下次启动重新评估 |
| 账号未登录 | 本次 session **永久 dismiss**（存 localStorage "percent.banner.account.dismissed=true"），除非用户点"登录" |

---

## 6. 关键不变性

- **启动永远不阻塞**：用户点完"开始使用"或老用户启动，永远能进主界面
- **数据永远本地**：登录只同步元数据；BYOK 调用不走 Percent 服务器
- **AI 功能永远可选**：BYOK 没配，AI 按钮显示"未配置"而不是消失（用户随时能配）

## 7. 实现优先级

按 ROI 排：

| # | 工作 | ROI | 估时 |
|---|---|---|---|
| 1 | 顶部 Banner 组件（基于现有 ByokRequiredBanner） | 🔴 | 0.5 天 |
| 2 | Banner 多条堆叠 + dismiss 逻辑 | 🔴 | 0.5 天 |
| 3 | 账号登录模态（从原 AuthView 改，复用 form） | 🟡 | 0.5 天 |
| 4 | 侧边栏底部账号区（未登录 / 已登录两态） | 🟡 | 0.5 天 |
| 5 | 权限 banner + 跳权限页 | 🟡 | 0.25 天 |
| 6 | 持久化 banner dismiss 状态（localStorage） | 🟢 | 0.25 天 |

总计 ~2.5 天。
