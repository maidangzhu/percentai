Problem

微信对话是日常, 但回消息是负担。

/ 01

"怎么回"是高频微决策

每条消息都要花 1–2 分钟: 用什么语气、要不要接话、怎么不冷场。回得累, 不回更累。

/ 02

隐性承诺混在闲聊里

"明天下午你过来看看" / "回头把资料发我" —— 说完就沉到聊天记录里, 转头就忘。

"上次答应过这个客户什么事来着?"
/ 03

截图给 AI = 上下文离开你 Mac

截图复制到 ChatGPT: 一来一回切窗口, 二来对话原文出了本机。云端 IM 助手更直接: 聊天记录在它那边。

Solution

常驻 Mac 角落的微信 AI 伙伴。

微信里按 Enter / 截个屏, 它读上下文给出建议; 你看一眼, 改一下, ⌘V 粘贴发送。

/ 按 Enter 自动留痕

按 Enter, 这条对话自动存本地。

微信里打完字按回车, 这条对话自动存到本地 SQLite, 不打扰你。

/ 帮我回

3 风格回复, 默认复制, ⌘V 发送。

气泡 → 3 风格回复 → 默认复制 → ⌘V。永远不替你发。

/ 记任务

识别隐性 todo, 弹确认卡, 你点头才入库。

从聊天里自动捞出"明天下午 3 点体检你来吗"这种, 让你确认再写库。

What's shipped

MVP 已能用, 范围先压在微信。

4 个核心动作 (在跑)

  • ✓按 Enter 自动留痕 — 微信里按下回车, 对话自动存本地
  • ✓帮我回 — 截屏 → 3 风格回复建议, 默认复制
  • ✓记任务 — 隐性 todo 识别 → 确认卡 → 写本地
  • ✓问屏幕 — 截屏 + 一句话, agent 工具调聊天/任务回复

3 个代码模块 (在跑)

  • ✓Tauri 客户端 — bubble 浮窗 + 主窗口, Rust + React
  • ✓Hono server — 截屏 / analyze / suggest / tasks / agent 路由
  • ✓Next.js CMS — 内部运营, 只读 Neon (账号/积分), 看不到聊天
end-to-end 延迟 ≈ 8s (持续压, 不是卖点)
Next + Ask

方向还在演化, 真实用户反馈最重要。
